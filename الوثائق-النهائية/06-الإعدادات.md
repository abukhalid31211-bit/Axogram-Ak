# S06 — الإعدادات (Settings)

> المراجع: حالة كل حقل (S00 §8: افتراضي/مخصص/dirty/خطأ تحقق/قيد الحفظ/فشل الحفظ)، G-CONFIRM، G-EXPORT.
> مبدأ: كل حقل يعرض الحالي + تلميص الافتراضي، وكل حفظ ناجح = Toast، وفاشل = حالة 3 معسببه (قاعدة مقفلة/قرص).

## 0. بطاقة القسم
- **الغرض:** ضبط النظام العام: API، حدود افتراضية، مسارات، إشعارات، أمان اللوحة، نسخ احتياطي، أداء.
- **الأثر العابر:** بيانات API تتحكم بصلاحية كل الأقسام (الحالة 5 العامة)؛ حدوده ترثها G-ACCOUNTS-STRATEGY؛ إشعاراته وجهة كل الأقسام.

## 1. S06-F1 — بطاقة النظام (أعلى القسم)
الإصدار | حالة الخدمة 🟢/🔴 | المساحة (مستخدم/متاح — تحذير <15%) | Uptime | API مضبوط؟ (✅/❌ سريع ──► F2) | اختصار «فحص الإعدادات الذكي»: يفحص (API، مسار كتابة، وجهة إشعارات، نسخة أخيرة) ⟶ نتيجة 🟢/🟡/🔴 مع روابط الإصلاح.

## 2. S06-F2 — مفاتيح API تيليجرام (إلزامي)
- API ID + API Hash: «الحالي: •••• (مخفي)» + [👁️ إظهار] (تأكيد كلمة مرور اللوحة) | حقل جديد + 💾.
- تحقق صيغة فوري (ID أرقام / Hash 32 hex — خطأ تحت الحقل).
- «🔍 اختبار الصحة» ⟶ ⏳ ⟶:
  - ✅ «يعمل بشكل صحيح (تم الاتصال بـ DC…)»
  - ❌ `API_ID_INVALID` / `CONNECTION_API_ID_INVALID` ⟶ «المفاتيح غير صالحة»
  - ❌ `API_ID_PUBLISHED_FLOOD` ⟶ «هذا الـ api_id منشور وممنوع — أنشئ واحداً جديداً» (حالة منع مطلق حتى الاستبدال)
  - ❌ شبكة/بروكسي ⟶ «تعذر الوصول — تحقق من الاتصال» (لا يُجرم المفاتيح!)
- دليل: my.telegram.org (أربع خطوات نصية) + ملاحظة «تُضبط مرة واحدة».
- الأثر: صالح ⇒ فتح الأقسام؛ غير الصالح/الغائب ⇒ بانر عام ثابت + تعطيل العمليات بنص السبب ورابط هنا.

## 3. S06-F3 — الحدود الافتراضية اليومية
لكلا: إضافة [20] | تجميع [500] | DM [30] | قروبات [25] | تأخير العمليات [60–120ث] | عمليات قبل التبديل [5] | راحة بعد كل N [20] بمدة [15–30د].
- تلميحات التوصية تحت كل حقل (⚠️ «>50 عدواني»…).
- «🧠 الحدود الذكية» مفتاح عام: تفعيلها يحوّل المدخلات للعرض فقط مع شرح القاعدة (عمر/صحة/FloodWaits).
- حالة الحفرة: حد=0 معناه «معطل من هذا النوع» (يظهر توضيح).

## 4. S06-F4 — مسارات التخزين
جلسات `./sessions` | ملفات `./exports` | سجلات `./logs` | نسخ `./backups` | قوالب `./templates`:
- لكلٍّ: الحالي + حقل جديد + «🔍 اختبار» ⟶ ✅ «صالح وقابل للكتابة» | ⚠️ «غير موجود — سيُنشأ عند الحفظ؟ [تأكيد]» | ❌ «غير قابل للكتابة» | ⚠️ «مساحة منخفضة».
- 🧹 تنظيف: سجلات>30ي | CSV>60ي | تقارير>90ي (كل بند: حجم/عدد ⟶ حذف عادي) | تنظيف شامل (خطير). حالة «لا شيء للتنظيف».

## 5. S06-F5 — إشعارات النظام (الوجهة الموحدة)
- مفتاح عام + مجموعات: حسابات (حظر/تقييد/استعادة/انهاء تسخين/تجميد❄️) | عمليات (اكتمال كل نوع) | أخطاء (FloodWait/فشل/حرج/موت بروكسي) | تقارير تلقائية (يومي HH:MM / أسبوعي يوم).
- الوجهة: [📱 حساب: Telegram ID/@username] أو [👥 قروب إشعارات: رابط ──► تحقق G-GROUP-LINK + عضوية حساب الإرسال] — للقروبات فقط كما هو النطاق.
- «🔍 اختبار الإرسال» ⟶ ⏳ ⟶ ✅ «وصل» / ❌ «فشل: USER_IS_BLOCKED (الحساب حظرك) / معرّف غير موجود / بروكسي».
- حالة «الوجهة غير مهيأة» = بانر في S04/S05/S07/S08/S09/S10 (متبوع هنا).
- 💾 حفظ.

## 6. S06-F6 — الأمان والحماية العامة (Defaults)
- الحدود الذكية (تفصيلها التشغيلي في S08-F3؛ هنا السوكيات الافتراضية القابلة للتوريث).
- مستوى الأمان العام: 🟢 محافظ | ⭐🟡 متوازن | 🔴 عدواني (يطبّق presets على G-PROTECTION).
- سلوك عند الأخطاء (FloodWait/حظر حساب): اختيارات G-PROTECTION الافتراضية.
- ☑️ تشفير ملفات .session ──► يفتح S08-F9 (مالك التنفيذ هناك).
- 💾 حفظ.

## 7. S06-F7 — اللغة والمظهر
- اللغة: العربية⭐/English/… ⟶ تبديل فوري (RTL⇄LTR تلقائياً؛ أسماء الحالات تقع في ملفات i18n).
- المنطقة الزمنية: بحث (Asia/Riyadh) + قائمة شائعة + الحالي (UTC+3) — تُستخدم لكل «HH:MM» والجداول الزمنية والتصفير S06-F10.
- تنسيق التاريخ/الوقت (3 صيغ / 12–⭐24س).
- حفظ. حالة خطأ: اسم منطقة غير معروف ⟶ رفض محلي بأقرب اقتراح.

## 8. S06-F8 — قاعدة البيانات
النوع (SQLite/PostgreSQL) | الحجم | السجلات | أزرار:
- 🔍 فحص سلامة ⟶ ⏳ ⟶ ✅ سليمة | ❌ «مشاكل: {قائمة}» + زر إصلاح (خطير — ينصح بنسخة أولاً).
- 🗜️ VACUUM: «سيقلل ~X→~Y MB» ⟶ تأكيد ⟶ ⏳ (تظهر حالة «قفل قاعدة مؤقت — العمليات تُكمل لكن بطيئة»).
- 🔄 نسخ الآن ⟶ ملف قاعدة عبر G-EXPORT.
- 📤 تصدير CSV (جداول مختارة☑️) / SQL Dump.
- 🗑️ حذف سجلات قديمة (30/60/90/مخصص يوم) — خطير + عدّاد قبل/بعد.
- حالة دورية معروضة: «مقفلة حالياً (SQLite busy)» لا تعتبر خطأً — تُعرض كملاحظة.

## 9. S06-F9 — التسجيل (Logging)
مستوى: 🔴Error | 🟡+Warning | ⭐🟢+Info | 🔵Debug (تحذير حجم). حجم الملف قبل الأرشفة (10/⭐50/100/مخصص MB) | ☑️ ضغط القديمة | ☑️ حذف بعد X يوم | ☑️ طلبات API التفصيلية (تحذير خصوصية: لا يسجل كلمات مرور/رموز OTP — يُقنَّع إجبارياً) | ☑️ أزمنة الاستجابة.
أزرار: [📂 عرض آخر 100 سطر (نافذة نصية بحث/تنزيل)] [🗑️ مسح الكل (خطير)] [💾].

## 10. S06-F10 — الجدولة التلقائية العامة
☑️ تصفير العدادات يومياً (وقت HH:MM افتراضي 00:00 — يظهر في S04) | ☑️ فحص الحسابات يومياً (وقت + تقريره ──► S01-F6 وضع مجدول) | ☑️ فحص البروكسي (─► S05-F6 جدولته) | ☑️ نسخ احتياطي (يومي/أسبوعي/كل X أيام) | ☑️ تنظيف ملفات (أقدم من _ يوم) | ☑️ إعادة تشغيل جلسات منقطعة (يقوم بإعادة فتح الاتصالات عند الإقلاع — مرتبط G-BOOT) | 💾.

## 11. S06-F11 — أمان الوصول للوحة (G-AUTH)
- تغيير بيانات الدخول: بريد جديد | كلمة حالية | جديدة+تأكيد ⟶ 💾 ⟶ ✅/❌ (صيغة بريد/كلمة ضعيفة `<8` تُرفض مع شرط القوة).
- Session Timeout: 30د/1س/⭐8س/24س/مخصص دقائق.
- تقييد IP: ☑️ قائمة بيضاء + حقل متعدد «Done» (تحقق CIDR/IP) — تحذير: «سيتم طرد الجلسات المخالفة فوراً».
- سجل محاولات الدخول: جدول (وقت|IP|نتيجة) — فلتر ناجح/فاشل.
- «🔴 تسجيل الخروج من جميع الجلسات» (خطير) — جلسات الويب فقط.

## 12. S06-F12 — النسخ الاحتياطي والاستعادة
### نسخ الآن
محتوى ☑️: جلسات (حذر) | قاعدة | إعدادات | قوالب | CSV | ☑️ تشفير الملف (كلمة مرور + تأكيدها — «فقدانها = فقدان النسخة») + مسار ➤ ⏳ ⟶ ✅ «الحجم X MB» + G-EXPORT مرفق مع فحص الحد 2GB/4GB/50MB-بوت.
- لافتة دائمة: «آخر نسخة: منذ X يوم» (🟢<7 / 🟡<30 / 🔴 أبداً).
### استعادة
مسار ملف + كلمة مرور إن مشفر (❌ «كلمة خاطئة/ملف تالف») ⟶ «تحليل محتوى: جلسات X | قاعدة | …» + تحذير «سيستبدل الحالي» + ☑️ انتقائية لكل جزء ⟶ تأكيد خطير ⟶ ⏳ ⟶ ✅ «تتطلب إعادة تشغيل — [إعادة الآن?] (G-BOOT سيلتقط العمليات الجارية مع توصية لا استعادة أثناء عمليات جارية: تُمنع وتشرح».)

## 13. S06-F13 — الأداء
العمليات المتزامنة [3] (1–10 + ⚠️ حمل) | حجم Cache [256MB] | «مسح Cache الآن» (عرض حجم + تأكيد) | Request Timeout لـAPI [30ث] | محاولات إعادة [3] | 💾 (معظم تغييراته تحتاج إعادة تشغيل جزئية: «ستطبق للاتصالات الجديدة»).

## 14. S06-F14 — معلومات النظام
الإصدار | تاريخه | Python/Telethon/DB/OS | اعتماد الموارد CPU/RAM/Storage (حي) | عنوان السيرفر | «🔄 فحص تحديث» ⟶ ✅ أحدث / 🆕 «v… — سجل التغييرات» (عرض نصي؛ تحميل خارجي يدوي).

## 15. S06-F15 — إعادة الافتراضي
(الحدود/الإشعارات/الأمان فقط) كلٌّ تأكيد عادي — و«🔴 كل الإعدادات» تأكيد خطير بكتابة «RESET» + لافتة: «لن تُحذف حساباتك أو بروكسيهاتك» ⟶ فورية Toast وعودة لصفحة القسم.
