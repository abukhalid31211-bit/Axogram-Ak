# S08 — أدوات الأمان (Security Tools)

> المراجع: ACCOUNT FSM (S01/S00 §3.3)، G-BLACKLIST، G-OPS، G-ERR (خصوصاً أخطاء «الانتظار الإجباري»: SESSION_TOO_FRESH/PASSWORD_TOO_FRESH/FRESH_*).

## 0. بطاقة القسم
- **الغرض:** موقف الأمان الكلي: قوائم سوداء عالمية، حدود ذكية، تدقيق، أجهزة متصلة، مراقبة حظر حية، تجميد ❄️، 2FA، تشفير، طوارئ.
- **قاعدة:** عمليات هذا القسم «حساسة» — معظم أفعالها قد يصطدم بحمايات تيليجرام للجلسات الحديثة؛ كل نتيجة انتظار تُعرض كحالة «مؤجل إجبارياً⏳ حتى T» وليست خطأً.

## 1. S08-F1 — لوحة القسم
حالة الأمان العامة (🟢 ممتاز/🟡 تحذير/🔴 خطر) بحساب مرجّح من عناصر الأدنى | تنبيهات نشطة X | محظورة/مقيدة/مجمّدة اليوم | FloodWaits اليوم | درجة أمان الأسطول XX% + لافتة 🔒 إن نظام مقفل.

## 2. S08-F2 — القائمة السوداء العالمية ⟶ G-BLACKLIST(mode=users)
الأسباب تُحقن من: S03 (خصوصية/فشل متكرر)، S09 (حظر الحساب)، S10 (طرد/محتوى)، ويدوياً. تقرأها كل الأقسام قبل أي استهداف.

## 3. S08-F3 — الحدود الذكية (Smart Limits)
- شرح: «يراقب سلوك تيليجرام ويكيّف السرعة/الحدود تلقائياً».
- قواعد ☑️ (كلها «أخطاء ⟶ رد فعل»): تقليل السرعة بعد X FloodWaits (3) | زيادة التأخير عند تقييد (+50%) | إيقاف مؤقت عند تقييد ≥X حسابات (3) | خفض حدود الجدد (<30ي؛ −50%) | زيادة القدامى (>6ش؛ +30%) | إيقاف إن الفشل >X% (30%) | تعديل التأخير بوقت اليوم | مراقبة معدل الاستجابة.
- مستوى عام: 🟢/⭐🟡/🔴/✏️ مخصص (4 حقول) — يتزامن مع S06-F6 ولا يتعارض مع خصوصيات الحساب S01-F10 (تشرح الأولوية: حساب < عالمي < ذكي).
- «جدول الحدود الموصى بها لكل حساب» (عمر|صحة|موصى|موصى تأخير) + [✅ تطبيق الآن] ⟶ ⏳ ⟶ «حُدّث X حساب» (الجدد بعناية).
- «📊 تأثير الحدود الحالية» (مقارنة قبل/بعد: حظر%، FW/يوم، إنتاجية — حالة «لا بيانات كافية بعد»).

## 4. S08-F4 — فحص أمان شامل (Security Audit)
= G-OPS(type=audit) بمراحل معروضة: «الحسابات ⟶ الجلسات ⟶ البروكسي ⟶ الأجهزة ⟶ السجلات المشبوهة ⟶ معدلات FW ⟶ الحسابات عالية الخطورة ⟶ سلامة القاعدة» [i/8].
- اكتمال: بطاقة 🟢X نقطة سليمة | 🟡Y تحذير | 🔴Z حرج + درجة XX/100 + جدول (عنصر|حالة|توصية|رابط إصلاح).
- زر «🔧 إصلاح تلقائي للممكن» (قوائم: جلسات ميتة ⟶ أرشفة، بروكسي ميت معيَّن ⟶ فك، حسابات ضعيفة ⟶ تسخين S01-F8) ⟶ ⏳ ⟶ «أُصلح X» وتقرير الباقي لليدوي.
- «فحص حسابات محددة»: G-ACCT-PICK. «⏰ جدولة دورية»: يومي/⭐أسبوعي/شهري/مخصص — آخر تنفيذ وحالته تظهر هنا.

## 5. S08-F5 — مراقبة الأجهزة المتصلة (Active Sessions)
- جدول الحسابات: (عدد أجهزة|آخر نشاط|تنبيه⚠️) — «تنبيه» إن جهاز غير معروف (قاعدة: تطبيق/IP/موقع لم يُرَ سابقاً).
- نقرة حساب (يداني: جلب حي `account.getAuthorizations` — ⏳):
  - قائمة الأجهزة: جهاز|تطبيق|إصدار|IP|موقع|آخر نشاط + شارة «الحالية (جلسة الأداة)» لا يمكن إنهاؤها.
  - [❌ إنهاء جهاز] / [❌ إنهاء كل الأخرى] — كلّه بمودال خطير ⟶ نتائج per-جهاز:
    | النتيجة | السبب |
    |---|---|
    | ✅ أُنهيت | — |
    | ⏳ «انتظر حتى {T}» | `SESSION_TOO_FRESH_X` / `FRESH_RESET_AUTHORISATION_FORBIDDEN` — يُبرمج تلقائياً ويظهر كمهمة مؤجلة |
    | ⏳ «كلمة المرور غُيّرت حديثاً» | `PASSWORD_TOO_FRESH_X` |
    | ❌ فشل | جلسة ميتة للحساب نفسه (⟶ account_state) |
- «🔍 فحص الكل» ⟶ ملخص: «حسابات بأجهزة ⚠️: X» + [إنهاء المشبوهة للكل] (خطير + نفس حالات الانتظار لكل واحد — جدول نتائج).

## 6. S08-F6 — مراقب الحظر الحي (Ban/Freeze Monitor)
- حالة مركزية: 🟢 نشطة / ⭕ متوقفة + «آخر فحص منذ X | التالي بعد Y» + فترة (5د/⭐15د/30د/ساعة/مخصص).
- ماذا يكشف (لكل حساب متولى): نشط/مقيد مؤقت مع T/مقيد دائم/محظور/مجمّد❄️ (منذ + مهلة الاستئناف إن عُلمت)/جلسة ميتة — المنطق ذاته S01-F6 (يعاد استخدامه).
- جدول حي: حساب|الحالة|منذ|الإجراء المتخذ. سجل الأحداث: وقت|حساب|حدث|إجراء (تنبيه مركزي + كتابة account_state + استبعاد S04).
- «عند اكتشاف حظر/تجميد»: إشعار فقط | ⭐إشعار+إزالة من التدوير | + إيقاف الحساب ساعة | + إيقاف كل العمليات. وجهة الإشعار S06-F5 (حالتها «غير مهيأة»).

## 7. S08-F7 — تنظيف الحسابات (Account Cleanup)
1. النطاق: الكل/مجموعة (S01-F7)/يدوي.
2. العمليات ☑️:
   - مغادرة قروبات غير ضرورية (احتفظ بأحدث _ ؛ ★ استثناء تلقائي: القروبات المضافة لقوائم S10 المستهدفة) — **حالة خاصة:** `USER_CREATOR` (الحساب منشئ القروب – لا يمكنه المغادرة) ⟶ يُجمعون في قائمة قرار: «[حذف القروب نهائياً منه (خطير إضافي)] [تخطي]».
   - حذف الرسائل المرسلة في القروبات أقدم من 24س/7ي/مخصص (حدود API على الحذف تُدار تلقائياً؛ `MESSAGE_DELETE_FORBIDDEN` يُتخطى بتسجيل).
   - مسح سجل DM (تحذير «لا تراجع») — مع خيار «للجهات المضافة تلقائياً فقط».
   - حذف جهات اتصال مضافة آلياً (التي علّمها التسخين).
   - إعادة ضبط جلسات متضررة (⟶ إعادة دخول S01-F2).
   - مسح كاش محلي.
3. تأخير بين الأفعال (حقل) ──► G-OPS(type=cleanup) per-account/h per-action حالة منفصلة + «⏸️/⏹️». إنهاء: جدول نتائج موحد (حساب×عملية).

## 8. S08-F8 — إدارة كلمات مرور 2FA
- جدول: حساب | مفعّل؟ | آخر تغيير | جلسة قادرة على التغيير (fresh-ok ⟵ قاعدة TOO_FRESH مسبقة).
- **تحديث حساب:** الحالية + الجديدة+تأكيد ⟶ 💾 ⟶ ✅/❌:
  - `PASSWORD_HASH_INVALID` (الحالية خاطئة بعدّاد) | `NEW_SETTINGS_EMPTY` | `PASSWORD_TOO_FRESH_X` (مؤجل إجباري) | `SRP_PASSWORD_CHANGED` («غيّرت خارجياً أثناء العملية — أعد الحصول على المعاملات وأعد المحاولة»).
- **تحديث جماعي موحّد:** تحذير صريح + تأكيد خطير.
- **تفعيل لأول مرة** (ليس له 2FA): الجديدة + **بريد الاسترداد** ⟶ تسلسل:
  - `EMAIL_INVALID` (بريد غير صالح) ⟶ تصحيح.
  - `EMAIL_UNCONFIRMED_X` ⟶ خطوة إدخال «رمز البريد (X خانات)» — أُرسل لبريدك (حالة انتظار رمز + زر إعادة إرسال) — `EMAIL_VERIFY_EXPIRED` («انتهت صلاحيته — أُعيد») / `EMAIL_HASH_EXPIRED` / `CODE_INVALID`.
  - نجاح ⟶ ✅ + توصية «حفظ الإعدادات».
- **فقدان كلمة مرور لحساب:** زر خاص على الصف: محاولة استرداد — `PASSWORD_RECOVERY_NA` («لا بريد معيّن — الخيار الأخير: إعادة تعيين بانتظار أسبوع `2FA_CONFIRM_WAIT_X` → قد يحذف الحساب!» تأكيد خطير مضاعف) / إرسال رمز ⟶ `PASSWORD_RECOVERY_EXPIRED`.

## 9. S08-F9 — تشفير الجلسات والبيانات الشخصية
- الحالة: مفعّل/معطل + عدد الملفات.
- ☑️ تشفير .session (AES-256): إدخال/توليد مفتاح ⟶ إنذار: «المفتاح يُعرض مرة واحدة — صدّره/احفظه خارجياً» (زر تنزيل ملف نصي بالمفتاح) ⟶ تأكيد خطير ⟶ ⏳ (X/Y ملف) ⟶ ✅.
- ☑️ تشفير الإعدادات/قاعدة البيانات (يطلب قائدةً بإعادة تشغيل).
- «🔑 تغيير المفتاح»: الحالي ⟶ الجديد ⟶ ⏳ (فك القديم/تشفير بالجديد) — أي خلل: توقف آمن مع rollback وتقرير.
- «🔓 فك التشفير مؤقتاً للترحيل» (خطير + زمن مؤقت اختياري).
- **حالة خطرة:** «مفتاح مفقود» عند الإقلاع — الحسابات المشفرة تظهر «🔒 مقفلة» (غير قابلة للاستخدام/الفحص) في كل الأقسام حتى إدخاله (شاشة إدخال أولى G-BOOT).

## 10. S08-F10 — الاستجابة للطوارئ
| الزر | السلوك | الحالات |
|---|---|---|
| 🔴 إيقاف جميع العمليات الآن | إشارة توقف فورية لكل `job_state` | تأكيد خطير ⟶ «توقف X (حُفظت نقاطها)» |
| 🔒 قفل النظام | يمنع أي جديد + كل الواجهات الحالة 5 مع بانر أحمر (S00 §2) | تأكيد خطير؛ «فك القفل» بكلمة المرور |
| 🗑️ حذف طارئ للجلسات الحساسة | اختيار الكل/محددة | كتابة كلمة استبعاد + عدّاد 5ث — نتيجة «حُذف X (أرشيف محلي اختياري مشفر أولاً)» |
| 📢 تنبيه طارئ | حقل متعدد ⟶ وجهات إشعارات S06-F5 (+☑️ Saved) | لكل وجهة ✅/❌+سبب (`USER_IS_BLOCKED`…) |
| 🔄 إعادة تشغيل | خدمة فقط / السيرفر كامل | تأكيد ⟶ G-BOOT عند العودة (S00 §11) |

## 11. S08-F11 — تنبيهات الأمان
☑️ حظر/تقييد/تجميد فوري | FW متكرر (>X بحقل 5) | نشاط جلسات مشبوه | موت بروكسي نشط | فشل اتصال حساب | انتهاء جلسة قريب | الفشل >X% | تقرير أمان يومي/أسبوعي + [🔍 اختبار] (⟶ حالة S06-F5) + 💾.

## 12. S08-F12 — تقارير الأمان
يومي (FW/حظر/تقييد/تجميد/تنبيهات + درجة اليوم) | أسبوعي (مقارنة + رسم حوادث + الأعلى تعرضاً) | «📊 أنماط الحظر» (متى/أي عمليات/أي حسابات + توصيات) | تصدير شامل بفترة ──► G-EXPORT.

## 13. UI/UX خاص
- درجة الأمان = بطاقة كبيرة بعدّاد دائري + قائمة أسباب تستحقها (روابط إصلاح فورية).
- كل زر طوارئ بلون مميز ومحمي بـfocus-trap دقيق وعدّاد (لا نقرة مزدوجة).
- Mobile: مراقب الحظر يدعم إشعارات متصفح Push عند فتح الصفحة (تطلب إذناً — حالة: ممنوع/مفعّل).
